# Vetro

Vetro is a manga and comic reader for Android based on Mihon and TachiyomiSY.

## Features

- Custom reading controls and gestures
- Vertical (webtoon), left-to-right, right-to-left, and double-page reading modes
- Offline reading and chapter downloads
- Progress tracking with AniList, MyAnimeList, and Kitsu
- Backup and restore support

## Download

Pre-built APKs are available on the [releases page](https://github.com/anaretete/vetro/releases).

## Building

Requires Android Studio Ladybug or newer and JDK 17+.

```bash
git clone https://github.com/anaretete/vetro.git
cd vetro
./gradlew assembleStandardRelease
```
